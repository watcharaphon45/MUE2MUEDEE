# แจ้งเตือนผลการทำรายการ

เพิ่ม `NotificationService` และ toast กลางมุมขวาบนที่แสดงบนทุกหน้า รวมถึงหน้าต่างฟอร์ม โดยแบ่งเป็นสำเร็จ (เขียว), ติดเงื่อนไข/ตรวจสอบข้อมูล (เหลือง) และระบบผิดพลาด (แดง)

`notificationInterceptor` ใช้ข้อความ `ApiResponse.message` จาก API:

- POST/PUT/PATCH/DELETE สำเร็จ: แจ้งสีเขียว
- การเสนอราคาที่ `data.needsApproval = true`: แจ้งสีเหลือง
- HTTP 4xx และ response ที่ `success = false`: แจ้งสีเหลือง
- HTTP 5xx และปัญหาการเชื่อมต่อ: แจ้งสีแดง
- การอ่านข้อมูลสำเร็จและการต่ออายุ session ไม่แสดงข้อความสำเร็จ
- Error ยังคงถูกส่งกลับให้หน้าที่เรียก API เพื่อแสดงคำแนะนำหรือปุ่มลองใหม่

ฟอร์มหลักของ Login, รับซื้อ, ขาย/POS, คลังสินค้า, ข้อมูลหลัก, ตั้งค่าร้าน และ Super Admin แจ้งสีเหลืองเมื่อข้อมูลไม่ครบ โดยคำแนะนำที่ช่องกรอกข้อมูลยังคงอยู่

แจ้งเตือนจะแสดงหลังคำขอ API ทั้งหมดเสร็จและ Loading ปิด ไม่เริ่มนับเวลาระหว่างที่หน้าจอถูกบล็อก ข้อความซ้ำชนิดเดียวกันรวมเป็นรายการเดียว และคำขอหลายขั้นตอนใน action เดียวกันใช้ข้อความสำเร็จล่าสุด

แสดงครั้งละไม่เกิน 4 รายการ ส่วนที่เหลือรอคิว ปิดเองใน 4.5/7/9 วินาทีตามชนิด หรือกดปิดเองได้ ชี้เมาส์และโฟกัสคีย์บอร์ดจะหยุดเวลาเพื่อให้อ่านได้ครบ ข้อความรองรับการตัดบรรทัดบนมือถือและไม่ตีความเป็น HTML

การสลับร้านที่ต้องโหลดหน้าใหม่จะเก็บข้อความสำเร็จใน session storage อายุสั้นและนำมาแสดงครั้งเดียวหลังเปิดหน้าใหม่

ตรวจด้วย unit tests ของ service/interceptor/component และ browser กับ API จำลอง ทั้งจอ 1440px และ 390px โดยไม่เปลี่ยนข้อมูลร้านจริง
