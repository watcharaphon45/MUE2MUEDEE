# Loading กลางและการบล็อกหน้าจอ

ทุกคำขอที่ส่งผ่าน Angular `HttpClient` จะแสดง Loading กลาง รวมถึงโหลดข้อมูล บันทึก ลบ เข้าสู่ระบบ สลับร้าน และอัปโหลดรูป โดยลงทะเบียน `loadingInterceptor` เป็นตัวแรกของชุด interceptor

- `LoadingService` นับคำขอที่กำลังทำงานและปลดล็อกหลังคำขอสุดท้ายสิ้นสุด
- จบคำขอทั้งสำเร็จ ผิดพลาด และ unsubscribe ผ่าน `finalize` จึงไม่ทิ้งสถานะ Loading ค้าง
- รองรับคำขอพร้อมกัน retry และการเรียก API ต่อกันหลังบันทึกข้อมูล
- Angular CDK Dialog แสดง Loading เหนือหน้าและ modal เดิม บล็อกการคลิก เลื่อน และแป้นพิมพ์ของแอป
- เนื้อหาหลักใช้ `inert` และ `aria-busy` ขณะรอ API โฟกัสอยู่ใน Loading และไม่ปิดด้วย Escape/คลิกพื้นหลัง
- คืนโฟกัสและการเลื่อนหน้าเมื่อปลดล็อก ข้อผิดพลาดของแต่ละหน้ายังคงแสดงหลัง Loading ปิด
- คำขอที่ยังไม่ได้ subscribe จะไม่นับเป็นการโหลด และ release function เรียกซ้ำแล้วไม่ลดจำนวนเกินจริง

งาน asynchronous ที่ไม่ได้ใช้ `HttpClient` สามารถใช้ `const finish = loading.begin()` แล้วเรียก `finish()` ใน `finally` เพื่อใช้ Loading เดียวกันได้ ส่วนการโหลดไฟล์ static ผ่านแท็ก `<img>` และหน้าต่างพิมพ์ของ browser ไม่ใช่คำขอ API ผ่าน interceptor นี้

ทดสอบคำขอพร้อมกัน API ล้มเหลว การยกเลิก อัปโหลด retry การเรียกคำขอต่อเนื่อง การบล็อกหน้าจอ และ modal เดิมที่ยังเปิดอยู่ โดยใช้ HTTP จำลองและ browser ที่จอ 1440px/390px
