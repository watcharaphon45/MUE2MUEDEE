# Modal ยืนยันรายการ

เปลี่ยน browser `confirm` 4 จุดและ `alert` 1 จุดเป็น modal ผ่าน `ActionDialogService` โดยใช้ Angular CDK Dialog ที่มีอยู่แล้วในโปรเจกต์

จุดที่เปลี่ยน: เปิด/ระงับร้านค้า, ลบต้นทุน, ลบรูปแบบสติ๊กเกอร์, คืนค่ารูปแบบสติ๊กเกอร์ และแจ้งข้อผิดพลาดเมื่อเปิดระบบพิมพ์ไม่ได้

เพิ่มการยืนยันให้การอนุมัติราคา ตอบรับ/ปฏิเสธข้อเสนอ และรับสินค้าเข้าคลังในหน้ารับซื้อทั้งรายละเอียดและ wizard รวมถึงยืนยันยอดขายและจำนวนสินค้าก่อนบันทึก POS

- `confirm({ title, message, confirmText?, cancelText?, tone? })` คืน `Promise<boolean>` โดยส่งคำขอทำรายการเมื่อผลเป็น `true` เท่านั้น
- `notify({ title, message, confirmText?, tone? })` ใช้แจ้งข้อความด้วยปุ่มตกลง
- Escape, คลิกพื้นหลัง หรือเปลี่ยนหน้า ถือเป็นยกเลิก
- เปิดได้ครั้งละหนึ่งหน้าต่างเพื่อป้องกันการรอยืนยันหลายรายการจากการกดซ้ำ
- จำกัดโฟกัสอยู่ใน modal และคืนโฟกัสเมื่อปิด โดยเริ่มที่ปุ่มยกเลิกสำหรับรายการที่ต้องยืนยัน
- ฟอร์มจ่ายเงิน ยกเลิกใบขาย และลบข้อมูลหลักที่มี modal อยู่แล้วคงใช้การยืนยันในฟอร์มนั้น
- หน้าต่างพิมพ์ของ browser ยังใช้ `window.print()` ตามปกติ

ตรวจการกลับมาใช้ native dialog ด้วย `npm.cmd run check:dialogs` ส่วน browser checks ใช้ API จำลองและตรวจว่ากดยกเลิกแล้วไม่ส่งคำขอเปลี่ยนข้อมูล
