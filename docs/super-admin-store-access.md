# Super Admin: การเข้าถึงร้านค้า

บัญชีที่มี `users.is_super_admin = true` สามารถเลือกร้านที่เปิดใช้งานทั้งหมดได้ โดยไม่ต้องมีข้อมูลสมาชิกใน `user_stores` กฎนี้ใช้กับ Super Admin ทุกบัญชี ไม่อิงชื่อผู้ใช้

- เข้าสู่ระบบโดยไม่ระบุร้าน: เริ่มที่ `/super-admin/stores` โดยยังไม่มี `StoreId` ใน token
- รายการเลือกร้านมาจากร้านที่ `is_active = true` รวมถึงร้านใหม่เมื่อเข้าสู่ระบบหรือต่ออายุ token
- เมื่อเลือกร้าน: API ตรวจสิทธิ์จากบัญชีในฐานข้อมูล แล้วออก token ที่มี `store_id` ของร้านนั้น พร้อมสิทธิ์ `Owner` สำหรับการทำงานภายในร้าน
- ไม่มีการเพิ่มสมาชิกหรือเปลี่ยนเจ้าของร้านจริง จึงไม่เพิ่มจำนวนผู้ใช้/เจ้าของในข้อมูลร้าน
- การสลับร้านโหลดหน้าใหม่เพื่อล้างข้อมูลและฟอร์มจากร้านก่อนหน้า
- ร้านที่ระงับไม่สามารถเลือกเข้าใช้งาน แต่ยังจัดการเปิดใช้งานใหม่ได้จากหน้าส่วนกลาง
- ผู้ใช้ทั่วไปยังต้องมีสมาชิกที่เปิดใช้งานในร้านนั้น และคงบทบาทที่กำหนดใน `user_stores`
- ตัวกรองข้อมูลตามร้านยังทำงานตาม `StoreId` ที่เลือก ไม่มีการข้าม tenant filter

ไม่ต้องเพิ่ม migration หรือรัน SQL เพิ่มสำหรับบัญชี Super Admin ที่สร้างไว้แล้ว หลังนำโค้ดขึ้นใช้งานให้ออกจากระบบแล้วเข้าสู่ระบบใหม่

การตรวจสอบครอบคลุมโหมดส่วนกลาง การสลับร้าน การต่ออายุ token ร้านระงับ ผู้ใช้ทั่วไป การแยกข้อมูลตามร้าน และกรณีมีร้านเดียว โดยใช้ฐานข้อมูลทดสอบและ HTTP จำลอง
